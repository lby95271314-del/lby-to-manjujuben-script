# 人物行动、台词和情绪

写人物、把细纲落为正文、修对白或诊断人设失真时读取。先按原著人物来写；不要将所有主角改成冷静强势、所有对手改成大声辱骂。

## 1. 最小人物卡

对主要角色记录实际影响行为的内容：

`身份与处境｜长期诉求｜此刻目标｜怕失去什么｜资源与局限｜行为准则｜惯用策略｜语言习惯｜关系压力｜变化触发点`

人物的经历、价值判断、处事方式和外在行动应能连起来。内在需求与外在任务可以不同：想被认可的人此刻可能在争取署名，也可能因害怕失去关系而不愿公开证据。成长写成在新刺激下作出不同选择，并承担代价；不是突然换性格。

检查主要人物与对手各自的利益、资源与选择。对手可以想保住资格、遮掩失误或维持控制，行动要与所掌握的信息匹配；让其作出可信的反行动，不能为方便打脸而突然失去常识。配角对同一事件应有自身利害，不成为统一震惊的合唱。

记忆点可以是处理事情的习惯、说话节奏或有来源的物件。同一动作首次显示习惯、再次可改变含义、最后可以体现选择变化；仅在有戏剧用途时复现。不搬用参考图的戒指、伤疤、奶瓶等特定设定，也不要求每人都有口头禅。

## 2. 一句台词先确定“要让谁做什么”

每句重要对白先找对象、诉求和策略：试探、求证、拖延、交换、拒绝、维护、掩饰、威胁或示弱。策略会随对方反应变化，台词因此形成行动链。

修稿按以下顺序：

1. 去掉观众刚看见的动作、重复设定和无用寒暄；保留决定选择所需的信息。
2. 用具体人、物、时间、条件或损失替代抽象判断。
3. 按身份、时代、教育、关系距离和当下处境选择措辞，形成声音差异。
4. 保留人物没有说出的意图，让动作与言语可以不一致。
5. 核对听者的回应是否改变策略或局面；两人各念独白不构成有效交锋。

“短平快”指听得懂、信息聚焦，不要求每句愤怒、每句同长度。古风和书卷气人物可以文雅；重要信息需要完整表达。不要机械地把自然一句拆成多个口号，或添加当前人物不可能知道的讽刺。

## 3. 微型改写示范

以下为原创示意，仅展示方法，不作为每个故事的固定台词。

| 写法问题 | 改写 | 实际用途 |
|---|---|---|
| “我认为你没有尊重我的劳动成果。”太抽象 | “稿子是我改的。署名为什么没我？” | 指定争议与诉求，等待对方答复 |
| “你会为自己的所作所为付出代价。”没有行动支点 | “先别盖章。把第三页也给评委看。” | 用已有文件阻止程序，制造查证行动 |
| “她终于认识到自己不该再相信他。”无法直接拍 | 她看见代签栏，收回递到他面前的笔：“这次我自己签。” | 判断外化成选择，关系发生变化 |
| 两人复述双方都知道的十年旧事 | 对手递出当年的欠条：“你还欠我一次。”主角不接：“那次，我已经还了。” | 旧事成为当前交换和拒绝 |
| 仅写“她委屈，但很坚强” | 她抚平被揉皱的作品，放上验收台：“先看完，再决定要不要。” | 反应带出行动，避免泛化神态 |

这些片段只写已具备相应事实的情境；文件、欠条或规则必须在原著或补桥中成立。冷静反击不是一律不哭、不怒；情绪强弱由人物与刺激决定。

## 4. 潜台词与情绪过渡

对同一句话核对表面内容和真正行动：“慢慢来”可能是关心，也可能是在拖延审核；区别来自关系、处境、动作和后果。不要靠附注解释正文中完全看不出的潜台词。

情绪转换使用 `刺激 → 判断 → 反应/停顿 → 新选择`。由哭到笑需要新的信息、认知或策略；同样的新证据也可能使人物更害怕，而不是统一开心。对手的震惊、沉默、改口或补救应符合其知情状态。

重复台词若用于记忆或主题，复现时增加新处境、对象、代价或含义。能用一次行为证明的，不靠每集重复宣言。结尾不要用“游戏开始了”替代具体事件或下一步行动。

## 5. 演出与声音标记

动作独立写 `△`，语气简短置于角色后的括号，必要时注明说话对象或声音来源。不要给每句强加多个情绪标签、不可演的心理解释或整段动作。

OS 是观众听到的心声，VO 和画外按项目约定使用；信息传递依靠真实可听对白、物件、见闻或查证。配音计时包含心声与旁白，不能因为它们不在画面上说出就忽略其时长。

剧本需要实际台词；连续叙事细纲可转述意图。客户要求只要正文时隐藏创作分析，保留人物动作、声音与叙事时间信息。

## 6. 动作与对白共同改变选择

核对动作是否引发回应，回应是否触发下一行动；同步动作应与当前任务、物件或关系有关。动作结果和对手反应留真实容量。多功能场景、复杂动作同功能替换和修稿见 [adaptation-decisions.md](adaptation-decisions.md) 第5–6节。
