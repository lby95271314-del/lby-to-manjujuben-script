# 从小说到分集、分场和正文

整篇、多集或结构重写时使用；不要求局部润色重做全套。创作资料只记录影响决策的内容，已有合格细纲、人物设定和项目参数直接复用。

## 1. 先确认改编的承诺

从已读原著提炼一句可执行的主线：谁处在什么困境，为了什么目标采取什么行动，受到谁或什么阻碍，失败会失去什么。另记观众期待的核心体验：解谜、尊严恢复、关系回应、能力认可、温情或喜剧等。题材标签不能代替具体故事。

区分三类改编材料：

- 保留项：核心关系、人物行为准则、世界规则、重要因果、情感内核和结局。
- 可调整项：支线长度、工具角色、背景说明位置、重复事件、场景分布与表达方式。
- 待补项：未读结局、未见伏笔、缺失章节、尚未确定的集数或时长。不能以新编情节冒充原著事实。

新增重大身份、幕后关系、世界规则或改变结局属于重构；没有相关授权时，先在原著材料内完成改编，将额外方案单独列为可选。小幅补齐过渡动作、合理查证和反应可以直接做，但要与原著事实相容。

## 2. 从需求找到可演的冲突

对主角、主要对手和关键配角分别确认：长期诉求、眼下要办的事、可用资源、行为底线、怕失去什么。人物如何做事见 [character-dialogue.md](character-dialogue.md)。

选择真正推动本段的冲突轴，不强制四轴齐全：

| 冲突轴 | 需要落到正文的问题 |
|---|---|
| 主角与对手 | 两人争什么，双方分别怎样改变对方的选择？ |
| 主角与盟友/配角 | 同一目标下是否有不同手段、代价或优先级？ |
| 配角与对手 | 配角的选择如何改变主角的证据、风险或资源？ |
| 主角内在矛盾 | 想要的东西与不愿付出的代价如何迫使其作决定？ |

用 `目标 → 行动 → 阻碍/反行动 → 新选择 → 局面变化` 找事件。只说“她受到羞辱”不够；要知道她因此争取什么、对方如何阻止。对手的利益可以解释行为，不能自动免除其行为后果。外部偶然可启动事件，主要解决依靠角色已建立的行动。

## 3. 把原著事件重组为故事概述

先确认原著结局回答了什么问题，再倒查哪些行动、关系变化与伏笔必需。可以采用建立、对抗、收束的三幕视角，或以下七个节点定位；它们是功能检查，不是等长段落或固定集数比例：

| 节点 | 改编检查 |
|---|---|
| 开端 | 主角、处境、当前目标和异常是否可理解？ |
| 首个转折 | 什么事件迫使人物承担新的行动或代价？ |
| 首次重大挤压 | 原有办法为何不够，问题条件如何升级？ |
| 中点 | 新信息、胜败或选择怎样改变主角策略？ |
| 再次重大挤压 | 对手的反行动让人物失去或冒险承担什么？ |
| 最终转折 | 主角凭什么采取决定结局的行动？ |
| 收束 | 外在任务、核心关系和主角变化怎样落地？ |

短篇可以合并节点；原作多线结构可以另选结构。转折须由具体事件和行动带出，不把“冲突升级”“人物成长”当剧情。高潮前有积累，高潮后有反馈；结局兑现故事承诺，留白不等于主要因果未解释。

关键事件映射用以下列项，填写真实章节或段落定位：

| 原著位置/事实 | 戏剧功能 | 保留/合并/前置/删减/外化/补桥 | 落在哪集场 | 必须先成立的条件 |
|---|---|---|---|---|

前置揭示时追查人物是否更早知情；合并角色时追查权限、动机、关系与证据来源是否也能合并。删除一条支线之前检查它是否供给后来反转所需的支点。不要只改事件顺序却保留原顺序下才成立的台词。

## 4. 分集细纲：让一集有进展，也能接下去

先按戏剧任务分配事件，再估算配音、行动和反应所需时长。超过用户容量时压缩重复、合并同功能段落或提出取舍，不擅自扩集。

每集至少能回答：入场末态是什么；本集要办什么；人物怎样行动；遇到什么阻碍；发生什么实际变化；已承诺的反馈兑现了什么；剩下的具体问题是什么；下集从哪个状态继续。

可选择 `入口事件 → 试探/施压 → 局面改变 → 反馈与下一步` 的四段节拍。需要爆发时让反击有支点；温情、甜宠或喜剧可以通过选择、回应和误会澄清推进。安静的反应仍可有效，不能以持续辱骂或每集增加陌生人充当节奏。

本集的小任务应有结果或阶段进展，长线问题可以继续；不强制每集清除全部危机。前一集已呈现证据成立、授权生效或人物作出选择，下集应处理其后果，不退回未发生状态。

用户要连续叙事细纲时，每集写一段：明确人物动作、互动、信息和结果，转述台词意图。默认可用简表或短段落，以项目要求为准。不要把细纲中的“她提出质疑”直接当剧本台词。

## 5. 分场任务到正文

每场记 `地点与时间｜在场/声音人物｜眼下目标｜阻碍｜关键行动与反行动｜离场变化`，再写成既有格式。按地点和叙事时间分场，同地同时间连续事件不因每次情绪变化另建场。

把小说常见表达外化：

| 小说表达 | 剧本落法 | 保留限制 |
|---|---|---|
| 心理判断 | 刺激物、可观察选择、短对白，必要时保留心声 | 其他角色不能听见心声 |
| 概括性过程 | 选取改变关系/策略的关键事件，其余省略或简短过渡 | 不能省掉证据获得和角色改变立场的原因 |
| 背景长说明 | 当前争执使用的物件、文件、行为或必要旁白 | 不让角色给彼此讲双方已知的设定 |
| 人物很强/很坏 | 成功或失败的具体行动，以及他人的可见处境变化 | 不靠标签、围观惊叹证明能力 |
| 时间跳跃 | 清楚的字幕、场头、闪回与返回 | 查证依据在剧情时间上也须成立 |

动作描述交代谁对什么做了什么及结果；简短反应承接刺激。保留影响剧情的物件状态，如已签/未签、封存/拆开、持有者变化。镜头概述只强调关键视觉证据和反应，逐镜拍法交给下游。

## 6. 多集创作的台账

多集、悬疑或重大反转时，在 `创作资料.md` 使用必要的表；普通单场改稿无需填写全部。

**伏笔与反转表**：

| ID | 原著依据或补桥说明 | 观众/具体角色原判断 | 线索出现集场/节拍 | 相关人物如何获得信息 | 揭示与兑现集场 | 实际后果 | 未埋/已埋/已兑现/取消及原因 |
|---|---|---|---|---|---|---|---|

**承诺与承接表**：

| 集尾问题 | 本集已兑现什么 | 人物/证据/道具末态 | 下集首场承接 | 后续回答位置或待定 | 当前进度 |
|---|---|---|---|---|---|

已取消伏笔要删掉相关误导或重写用途；只读到节选时，未见的回答标记待补。规划的位置只是计划，写稿后更新为真实正文位置。不能把台账登记当作伏笔已在正文发生。

## 7. 修稿顺序

先核对因果与原著约束，再查人物行动与知情，然后查反转兑现和跨集承接，最后压缩对白、补反应、核算时长与场景。修台词不能掩盖主角没有证据或对手没有行动的问题。

审读发现无变化段落时，优先删并重复说明和同级冲突；仍须保留理解必要的铺垫。交稿资料与正文分开，按既有脚本校验。完整应用见 [adaptation-example.md](adaptation-example.md)。

## 8. 取舍、补戏与持续推进

需要扩写、原创补戏、来源追踪或分批续写时读取 [adaptation-decisions.md](adaptation-decisions.md)：四种操作、补戏边界、两种发动机、动作对白链和修稿依赖检查。已有有效剧情不强制重新分类。
