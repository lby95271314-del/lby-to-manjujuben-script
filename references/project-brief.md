# 项目参数与完整交稿包

先使用用户已经给出的信息，不重复询问。没有指定媒介时可沿用竖屏漫剧假设并说明；媒介会影响表演、旁白量和视觉复杂度。用户只要求局部改稿时，不强制重新规划全剧。

## 参数

`assets/project-config.json` 是可修改的范例，不是平台统一规则。校验器允许省略配置并使用默认值；未知字段、错误类型、负数预算和不合法声音标签会报配置错误。

| 字段 | 作用 |
|---|---|
| `target_seconds` | 每集目标秒数下限与上限；估算偏离时提醒。默认 `[45,80]` 取自五部横屏成片实测中位（45.0–75.1s） |
| `speech_chars_per_second` | 汉字、英文字母、数字的计数单位/秒；默认 4。英语较多时调整，不等同于词/秒。快嘴品种按 3.5–4.8 配置；用默认 4 估算快嘴集会低估时长 8–20% |
| `pause_seconds_per_dialogue` | 每行对白默认停顿；显式节拍的“停顿”会替代该默认值 |
| `max_scenes` | 每集场次数提醒；不等同于独立地点数 |
| `max_spoken_chars` | 含 OS、VO、旁白的配音预算提醒 |
| `max_dialogue_chars` | 单条台词字数上限，用于单行字幕排版；默认 `null` 关闭，横屏成片建议 14–18 |
| `pilot_seconds` | 试看段独立时长区间；默认 `null` 表示同样走 `target_seconds`。试看段实测为常规集的 1.6–4.3 倍，压不进常规集时用它单列 |
| `pilot_episodes` | 试看段覆盖的集数；默认 `1`（仅首集）。设 2–5 时前几集都走 `pilot_seconds`——高考第 2 集 128.7s 才是全集最长，首集反而不是 |
| `body_chars_range` | 正文量提醒，排除标题、人物标签及编剧注释 |
| `budget_policy` | `warn` 为提醒，`error` 将预算超限视为项目硬要求 |
| `aliases` | 别名到标准角色名映射；正文和人物名单使用同一映射 |
| `voice_tags` | `inner`、`remote`、`offscreen` 的项目标记，默认 OS、VO、画外；三者不可相同 |

完整创作还可在单独的交稿资料中记录目标媒介、受众、题材、总集数、免费集数、付费卡点、人物上限、独立地点预算和固定道具；这些不是当前校验配置字段，不伪装成单集脚本已经自动校验的项目。

声音标签只改变表达约定，不改变戏剧事实：内心独白仍不可被其他人物直接听到。别名不应覆盖另一个独立角色的姓名。

## 成片规格先量再写

单集时长、台词量和镜头数不要凭习惯定。有已上线参考片时先测四项：集数、单集中位时长、平均镜头长、单行字幕字数；没有参考片时按下列档位取，并在交稿资料里写明是假设。

| 档位 | 单集时长 | 单集台词 | 镜数 | 场数 |
|---|---|---|---|---|
| 竖屏短集（红果类） | 90–120s | 300–450 字 | 70–110 | 3–5 |
| 竖屏长集 | 150–300s | 500–900 字 | 120–220 | 5–8 |
| 横屏短集（AI 写实漫剧） | 45–70s | 160–260 字 | 30–60 | 2–3 |
| 横屏中集（爽文多点推进） | 65–80s | 260–380 字 | 25–45 | 2–4 |
| 横屏慢集（甜宠/日常，单线推进） | 60–90s | 130–260 字 | 25–50 | 2–3 |

时长重叠时按台词密度与推进方式选档，不只看秒数。项目预设（复制进项目配置的 JSON 片段，未列字段用默认值）：横屏短集 `{"target_seconds": [45, 60], "max_spoken_chars": 200, "max_dialogue_chars": 14, "pilot_seconds": [90, 130]}`；横屏中集 `{"target_seconds": [65, 80], "max_spoken_chars": 280, "pilot_seconds": [100, 160]}`；横屏慢集 `{"target_seconds": [60, 90], "max_spoken_chars": 200, "pilot_seconds": [110, 200]}`；快白品种 `{"speech_chars_per_second": 4.5, "target_seconds": [45, 60], "max_spoken_chars": 260}`；竖屏短集 `{"target_seconds": [90, 120], "max_spoken_chars": 420, "max_scenes": 5}`。

反推关系：`台词字数 ≈ 时长 × 2.2–4.5`（含静默；分阶段分档：试看段 3.5–4.5、中段 2.2–3.2、情感慢节奏 1.4–2.0）、`镜数 ≈ 时长 ÷ 档位均镜`（快切 1.2／标准 1.7／舒缓 2.8）、`单集原著字数 ≈ 台词字数 × 3–8`（爽文对白多取低值，情感文议论多取高值；飞鱼盛夏约 3344 字/集是上限标本）。**画幅先量再写**：可能是非标的（实测 1882×1080），字幕安全区与台词行宽按实际画幅折算。实测案例与方法见 [benchmark-cases.md](benchmark-cases.md)。

**试看段单独定长**：五部参考片的实测倍数是 1.60×–4.32×，"首集最长"不是铁律——高考首集 78.0s、第 2 集 128.7s 才是全集最长，元婴前两集基本并列。试看段（前 2–5 集）总时长与总信息量固定，内部分配自由：首集扛人物＋钩，次集扛规则＋第一波兑现。项目配置用 `pilot_seconds` 给试看段独立区间（如 `[90, 200]`），用 `pilot_episodes` 指定覆盖前几集（默认 1），其余集仍走 `target_seconds`；不设则全剧同一区间，第 3–10 集收敛后锁长。首集承担"人物、规则、钩子"三件事，压不进常规集，不要为对齐时长砍掉其中一项。

由原著总量估集数时，先用第三式算出集数区间，再按剧情转折点调整；不要先定集数再把内容硬塞或硬删。

## 合规替换表

改写前先列项目级替换项：性暗示与露骨描写、脏话、暴力细节、迷信与风水表述、真实机构与品牌名、可能引发地域或身份争议的称呼。品牌名与机构名分开处理：品牌名成片可保留（实测高考全片保留"劳斯莱斯"），但需评估商务与平台风险；机构实名按需换成泛称（实例：原著"隆城一中"改为成片"龙城一中"）。处理方式是"降级保留攻击性"——把直白词换成有杀伤力的委婉说法，保留人物原句的功能，不改成没有情绪的客套话。示例：原文的性交易指涉改为"随便的男人"，仍保留羞辱效果。替换项写进 `创作资料.md`，逐条过，不留"回头再改"。

## 完整交稿包

用户要求整包时，另写 `交稿资料.md`，与可校验的剧本正文分开：

1. **剧本信息**：题材、媒介、总集数、单集时长、预计总时长，用户指定的免费集数/卡点；未指定的商业参数标明待定，不编成事实。
2. **一句话故事**：通常约 50 字，写主角、困境、行动与核心看点，长度服从客户模板。
3. **完整故事大纲**：写清从开端到结局的主线、关键转折及因果；参考 500–2000 字，按项目调整，包含结局，不能只有卖点介绍。
4. **主要人物小传**：优先主角、主要对手及推动主线的配角；包括身份、年龄/外表、背景、性格、目标动机、关系、成长弧线，避免为所有路人编长传。
5. **分集梗概**：项目需要时，记录核心事件、变化、钩子及后续兑现位置；免费转付费卡点必须与实际分集对应。
6. **人物名对照表与数字表**：原著名→成片名的映射（实例：江澈/沈清/周曦楚/薛向阳 → 江叙/沈柠/周西楚/薛少阳；转写与平台简介还可能不一致，跨集稳定性只认此表），别名同时写进项目配置 `aliases`；自造数字（年龄、金额、时间）建一张数字表并全剧回查。

长篇改编或设计反转、情绪时，按 [story-methods.md](story-methods.md) 记录必要的原著事件映射、信息差和集间承接。用户已给出总集数时先评估可容纳的戏剧任务；需要调整集数则给出取舍依据，不自行忽略用户要求。没有指定集数时提出有内容依据的建议，不仅按原文字数换算。

可在交稿资料中简记观众期待（如尊严恢复、能力认可、关系修复、解谜或安全感）、首集核心问题、主要反转和伏笔兑现位置。这些是人工创作说明，不是新增 JSON 配置字段。

完整或多集改编按 [adaptation-workflow.md](adaptation-workflow.md) 组织故事概述、原著关键事件映射、分集细纲、分场任务与跨集台账；人物卡与对白处理见 [character-dialogue.md](character-dialogue.md)。用户已有定稿细纲时以其为基础，不凭创作参考更换主线。规划材料另存 `创作资料.md`，用户只要正文时不强制打包全部内部资料。

## 创作与制作审读

- 每集核心事件明确；事件结束应改变局面或人物选择。
- 强开场应来自冲突或异常；不为凑“黄金三秒”破坏理解与因果。
- 反转数量不固定；增加反转前检查铺垫、信息来源与后果。
- 主角和对手都应有具体目标与行动能力；侮辱、拉踩并非所有题材必需。
- 角色的道具、动作、说话方式形成记忆点，但不能每场重复口号。
- 旁白补必要信息，避免与已能看到的画面重复解释。
- 统计场次与独立地点；同一地点更换时间不必建立新的地点资产。
- 预估时长最终结合配音、表演和成片校正。
