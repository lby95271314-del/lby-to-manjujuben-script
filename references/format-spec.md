# 漫剧剧本格式规范（依据用户样例逐项提取）

本文档是唯一格式权威。所有改编成稿必须逐条符合。

## 1. 集结构

```
# 第三集【1min1s】
```

- `第X集` ＋ `【目标时长】`，格式 `XminYs`（如 `1min1s`、`1min30s`）。
- 每集 60~120 秒；每集以钩子收尾（悬念、反转、新危机、反击启动）。

## 2. 场结构

每集内按场景切分，结构固定为：

```
## 3-1 泰城云湾酒店豪华套房-内-日

出场人物：陈景川、陈母、许清雅、酒店工作人员

【镜头语言】…（灰）
【场景目标】…（绿）
【情绪】…（橙）

（正文：动作行 / 对白块 / 标注 / 字幕）
```

- 场次标题：`集号-场序 地点-内/外-日/夜`。地点写具体（“泰城云湾酒店豪华套房”，不写“酒店”）。
- `出场人物：`顿号分隔，主要角色在前、功能角色在后（含只有声音出场的 VO 角色）。

### 2.1 场次头三行标注（顺序固定）

| 行 | 颜色 | 内容写法 | 样例 |
|---|---|---|---|
| 镜头语言 | 灰 | 镜头/画面组织方式：景别、切换、插入物 | 海景套房全景、人物反应切换与手机拍摄画面插入。 |
| 场景目标 | 绿 | 本场戏剧任务一句话，落在“改变什么” | 建立陈家误认与全家福排斥，触发女主撤回供养 |
| 情绪 | 橙 | `情绪主调｜节奏点类型：展开说明` | 情绪：憋屈愤怒与反击期待｜虐点、压迫、悬念：陈家享受女主供养，却把许清雅纳入全家福并排除女主。 |

## 3. 正文元素

### 3.1 动作行

```
△ 陈景川、陈母和许清雅站在落地窗前，酒店工作人员在门口介绍套房，窗外可见海景。
```

- `△ ` 前缀，一句到两句，只写可被拍到的外显动作与神态，不写心理。
- 用于开场定场、动作插入、情绪外化（“眼眶发红”“握紧手机”）、转场。

### 3.2 对白行

```
陈母：我的天，我们真的住这里？
陈景川（VO）：已经托运了。
陈景川（OS）：又怎么了?
!苏晚晴：陈景川，你问我怎么才到？不是你把我一个人扔在路边的吗?
```

- 格式 `角色名：台词`；标点用全角。
- `（VO）`＝画外音：电话另一端、远端传声、不在现场的说话声。
- `（OS）`＝画外：人在现场但不在画面内。
- `!` 前缀＝本节拍关键台词（冲突核心句、金句、信息炸弹），生成时整行台词呈紫色强调，每场 2~5 处。
- 台词要短、口语、带情绪钩子；一段对白块通常 1~4 行。

### 3.3 字幕行

```
【字幕：前方排队27人】
【字幕：预计等待30分钟】
```

- 插入屏幕硬信息（数字、时间、地点），服务压迫感与紧迫感。

### 3.4 节拍标注（每个对白块后成对出现）

```
【蓝】揭示、伏笔｜建立陈家对豪华待遇来源的错误认知
【红】压迫、悬念｜陈家越确信待遇源于陈景川，后续失去特权时的反差越强。
```

- **蓝行＝剧情功能**：这个节拍在情节上做了什么、埋了什么。
- **红行＝情绪效果**：给观众什么情绪，并把效果推向后续期待。
- 两行说明**同一节拍**、主体一致、角度互补；红行常把后果延伸到“后续/反差/期待”。
- 格式 `标签1、标签2｜说明句`，说明句以句号结尾。

**剧情功能标签词表（蓝）**：揭示、伏笔、冲突、关系转折、承诺、兑现、铺垫、反转、收束
**情绪点标签词表（红）**：虐点、爽点、悬念、压迫、期待、反差

配对惯例（从样例归纳）：
- 铺垫误认 → 蓝`揭示、伏笔` / 红`悬念、压迫`（指向后续反差）
- 主角受辱 → 蓝`冲突、揭示` / 红`虐点、压迫`
- 女主亮底牌 → 蓝`揭示、伏笔` / 红`悬念、爽点`
- 反击落地 → 蓝`兑现、关系转折` / 红`爽点、悬念`
- 关系撕裂定局 → 蓝`冲突、关系转折` / 红`虐点、压迫`

### 3.5 边注

```
【边注】陈家误认豪华待遇源于景川
```

- 一句话（6~14字）概括所在节拍块的叙事动作，生成时置于页面右侧（花括号+小框位置）。
- 写“谁+干了什么/遭遇什么”，如：`行李被带走后彻底寒心`、`求丈夫补救遭拒`、`合照安排公开替代妻子`、`妻子揭穿座位待遇倒置`。
- 每场 2~5 个，放在节拍转折处，不是每块都有。

## 4. 改编写法（小说 → 剧本）

1. **保因果删枝叶**：保留推动核心冲突的人物动机与事件因果；删除环境铺陈、心理独白（可转为一句 △ 外显动作或 VO 独白）。
2. **信息炸弹前置**：小说里藏在后文的关键信息（如“三千万投资是女主管的”）提前到受辱场景内用 VO 揭示，构成当场反击支点。
3. **每块对白配节拍**：先问“这块在情节上干什么（蓝）”，再问“观众爽/虐在哪（红）”。
4. **反事实与对照**：样例常用“如果被丢路边的是她呢”“七年妻子 vs 顺路人”式对照台词制造虐点，改编时主动构造此类对照。
5. **集尾钩子**：停在决定刚做出、危机刚出现、反击刚启动的瞬间（如“那三千万先停了”后立即收）。

## 5. 中间稿标记 → Word 呈现对照

| 中间稿写法 | Word 呈现 |
|---|---|
| `# 第X集【…】` | 大号加粗集标题 |
| `## 场次标题` | 加粗场次标题 |
| `出场人物：…` | 加粗正文行 |
| `【镜头语言】…` | 灰底段落，文本呈 `【镜头语言：…】` |
| `【场景目标】…` | 绿底段落 `【…】` |
| `【情绪】…` | 橙底段落 `【情绪：…】` |
| `【蓝】X｜Y` | 蓝底段落 `【X｜Y】` |
| `【红】X｜Y` | 红底段落 `【X｜Y】` |
| `【边注】…` | 右对齐小字带边框 |
| `【字幕：…】` | 加粗正文行 |
| `△ …` | 普通正文行 |
| `角色：台词` | 普通正文行 |
| `!角色：台词` | 角色名黑字＋台词紫色 |
| `角色（VO/OS）：台词` | 同上规则 |
