# 漫剧剧本格式规范

这是默认语法；用户或客户的明确要求优先。脚本接受这里规定的中间标记，外部格式需先转换并核对原文，不能直接把导出成功视为转换正确。

## 1. 集与场

```text
# 第一集【1min20s】
## 1-1 陈家客厅-内-日
出场人物：苏晚晴、陈景川、陈母、酒店经理（仅声音）
【镜头语言】家庭合照与手机屏幕插入。
【场景目标】让晚晴发现自己的付出被公开归给别人。
【情绪】心寒转为决断｜压迫、期待：供养者被排除在家庭合照外。
```

集标题支持中文数字或阿拉伯数字；时长 `XminYs` 的秒部分为 0–59。场号必须与所在集一致，每集从场序 1 连续递增，不重复。跨集节选保留对应集标题，不能把第二集场号放在第三集标题下。

场标题格式为 `集号-场序 具体地点-内/外-日/夜/晨/傍晚/黄昏`。演员名单用顿号；声音角色可标 `（仅声音）`，普通对白角色必须在本场名单中。`旁白` 可不列入人物名单。别名通过项目配置映射，不由校验器猜测身份。

分析稿每场按顺序写镜头语言、场景目标、情绪三行。纯交稿稿件不强制这三行。画面概述不细分镜号、机位与视频生成提示词。

## 2. 动作与对白

```text
△ 苏晚晴停在门边，将礼盒放到脚旁。
陈母（催促）：清雅，站到景川身边。
!苏晚晴：我的位置，也给她了？
苏晚晴（OS）：这一次，我不会再替他们买单。
酒店经理（VO，电话另一端）：撤销授权需要您本人确认。
陈景川（画外，门外）：你在跟谁说话？
旁白（VO）：三年前，她替陈家还清了债。
```

△独立成行，只写能被呈现的动作、环境或神态；具体行为放在动作行，语气和简短同步动作可置于角色名后的括号。不同角色的对白单独成行，不加包住整句台词的双引号。`!` 是分析稿的关键台词强调，交稿输出去除该前缀。

本项目默认 OS=内心独白，VO=旁白/远端声音，画外=现场但不在画面内的对白。VO注明电话、广播等来源；内心独白不能影响其他角色的听觉反应。客户另有约定时在 `voice_tags` 统一，不混用两套定义。

对话标点使用全角冒号及中文问号、感叹号；导入稿出现半角冒号/问号/感叹号时报告提醒，不静默改变台词。一句台词的长度与题材、时长有关，避免机械拆成失去语气的碎句。

细纲可以概括台词意图，正文须写实际说出的句子。重要台词应有对象、诉求和策略，措辞符合人物身份、时代及关系；动作承接刺激与选择，避免用“很生气”“震惊”替代具体行为。改写方法见 [character-dialogue.md](character-dialogue.md)。

## 3. 节拍与分析

```text
【节拍】B1｜同步动作=4｜独立动作=2｜停顿=1
△ 苏晚晴举起手机，屏幕上显示她的付款记录。
!苏晚晴：三十晚的房费，哪一笔是你付的？
【蓝】揭示、冲突｜付款记录推翻陈景川出资的说法。
【红】爽点、期待｜供养者亮出证据，观众期待她撤回待遇。
【边注】付款记录戳破谎言
```

“节拍”是一个叙事动作，可含若干动作和对白。`B1` 等编号在本场唯一；节拍时间均为非负秒数，允许小数。

- **同步动作**：与本节拍配音并行的画面/动作。
- **独立动作**：必须在对白之外单独呈现的画面/动作。
- **停顿**：本节拍配音额外停顿总量，替代按对白行默认累加的停顿。
- 节拍时长 = `max(配音计数/语速 + 停顿, 同步动作) + 独立动作`。
- 明示节拍需给齐三项；没有显式节拍的旧稿仍可解析，但报告仅为配音下限，需人工补动作时间。角色对白在节拍内按顺序发生，不假定多人同时说话。

蓝注与红注对齐同一节拍，不按固定对白行数机械切段。蓝写发生的因果变化，红写情绪与期待；避免复述台词或复制上一拍分析。

设计反转时先明确原判断、伏笔和新证据，再写变化及反馈；情绪按刺激、判断、反应、后果推进。方法与范例见 [story-methods.md](story-methods.md)。设计卡另存创作资料，不直接加进可校验正文，不增加当前解析器不支持的标记。

蓝标签：揭示、伏笔、冲突、关系转折、承诺、兑现、铺垫、反转、收束。
红标签：虐点、爽点、悬念、压迫、期待、反差。
语法为 `【蓝】标签1、标签2｜说明` 和 `【红】标签｜说明`。说明非空，同一节拍各一条；分析稿的内容节拍必须配对。只有本场最后一个内容节拍可用 `【收尾】` 明示省略红注，仍必须有蓝注。

`【边注】` 是可选的 6–14 个计数单位叙事摘要，生成正文之后的右对齐带框段落；不是浮动侧栏，不强制每场数量。`【钩子】` 位于每集末尾，记录悬念和后续兑现计划，属于编剧说明，交稿版隐藏。钩子实际要发生在正文中，不能只写在说明里。校验器只检查说明存在，不证明钩子有效。

## 4. 字幕与叙事时间

```text
【字幕：三年前】
【闪回】
△ 苏晚晴将签好的担保书推到陈母面前。
【闪回结束】
【想象】
△ 手机上的授权状态变成“已撤销”。
【想象结束】
【字幕：授权撤销倒计时】
```

统一开始与结束标记，闪回/想象不嵌套，也不交叉；可跨场，但必须在所属集结束前闭合。结束后用动作或下一场标题明确回到现实的时间地点。导入支持 `【闪出】` 作为闪回结束别名，正式稿优先统一写 `【闪回结束】`。

闪回是叙事时间变化；淡入淡出是转场方式，不能仅因一个回忆没在前文出现就标成“淡入”。当前解析器不将转场效果当作时间标记。

## 5. 输出与检查

分析稿保留三行场头、蓝红注、边注，关键台词台词部分呈紫色。计时元数据与钩子说明显示为小号灰字。

交稿版隐藏所有分析、节拍计时与钩子说明；保留动作、对白、字幕及时间标记。`--markdown` 同时生成同一版本的 Markdown。两种版本共享正文，不分别改写。

配音量排除人物标签与标点，计算汉字、英文字母及数字；正文量在配音量之外计入动作与字幕文字，排除集场标题、人物名单和分析说明。注释量另计。配置的字数和时长范围按同一口径报告，不声称等同于所有客户的字数统计。

格式错误阻止导出；预算默认提醒，可通过 `budget_policy=error` 设为项目硬要求。剧本的动机、铺垫、钩子效果与可制作性另行审读。存在旧稿隐式节拍时不要把估算打印成准确的成片时长。

## 6. 旧稿迁移

先修复跨集场号；每场只写一次人物名单。旧稿末拍只有蓝注时补 `【收尾】`，其他内容节拍补齐蓝红。未写计时元数据的旧稿会报告配音下限，按需补完整计时，不自动捏造动作时长。

旧版本把 OS 用于现场画外。迁移时逐处确认声音含义：心声改用默认 OS，现场画外改为 `画外`；也可配置 `inner=心声、remote=VO、offscreen=OS` 延续客户约定。脚本不能从一句台词判断原作者的语义，禁止无检查地批量替换。
