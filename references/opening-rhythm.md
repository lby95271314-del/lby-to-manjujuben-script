# 黄金开头、节奏与反转的落稿方法

小说转短剧的首集、单集冷开场、节奏重写或留存问题诊断时优先读取。本方法重点是把吸引力写进实际动作和对白，而不是在编剧说明中贴“黄金开头”“节奏紧凑”的标签。类型选择见 [reversal-library.md](reversal-library.md)，人物声音见 [character-dialogue.md](character-dialogue.md)。

## 1. 从原著找开头，不从背景介绍开始

先找原著中已经成立的五种材料：迫近损失、反常事实、即将执行的决定、有代价的选择、明显失衡的关系。选与主线最近、观众最容易读懂的一件，让主角正在做事或被迫作决定。

开头尽快让观众读出：谁是当前关注对象；发生了什么异常或阻碍；此刻不处理会失去什么。先吸引，再用当下行动补最少信息。不是把身世、世界规则、所有人名和未来反转全塞进第一句。

短视频项目可以优先尝试前3秒出现一项可见事件或冲突信息；具体长度以用户预算、题材和理解成本决定。3秒只宜承载一个抓手，不要求在3秒内讲清全套设定或完成双重反转。动作与短对白可同步，不能用超过配音容量的长句冒充3秒开场。

## 2. 六种开头入口

| 入口 | 正文中先呈现什么 | 随后补什么 | 常见失效 |
|---|---|---|---|
| 迫近损失 | 要被执行的除名、交接、关门或限时决定 | 主角想保什么、可采取什么行动 | 只有受辱，没有任务或后果 |
| 反常事实 | 有可核对异常的物件、消息或人物行为 | 为什么反常、谁要查证 | 没有旧认知支撑的“震惊秘密” |
| 后果先行 | 原著中真实发生的结果或代价 | 清楚回到前因，进入导致结果的行动 | 为抓眼改写结果、假造危机或泄尽所有答案 |
| 艰难选择 | 主角面对两个有不同损失的选项 | 选择的原因与实际代价 | 选项口头成立，却没有执行压力 |
| 主动出手 | 主角已经在求证、救人、拒签或阻止某事 | 对手的有效反行动与主角局限 | 全能主角瞬间解决全部问题 |
| 关系反差 | 应该支持她的人作出相反行动 | 双方的关系、利害和当前目标 | 只靠角色歇斯底里制造强度 |

悬疑优先异常与可查证路径；逆袭可先呈现损失和反击期待；甜宠、温情、喜剧可以先呈现关系失衡、选择或有依据的反差。不能给所有小说加同一种羞辱场景。

## 3. 选择开头时做一次小比较

首集尚未定入口，或原稿开场明显偏弱时，内部构思2–3个有原著依据的短版本，按以下标准选一个进入正文；已有有效开头不强制另造备选，也不强制把备选全交给用户。

- 与主线距离：这个事件是否直接引出本集任务，而非无关猎奇？
- 理解门槛：不靠长旁白，观众能否读出当前阻碍和利害？
- 原著支点：异常、威胁和解决路径是否已存在或只是合理补桥？
- 主角行动：开场后她是否能尝试行动，而非被动挨骂很久？
- 后续容量：剩余时长能否兑现所许诺的阶段反馈？

只改开头，后续没有事件变化，不能算节奏升级。选择后回查被删掉的背景是否仍在必要位置出现、被前置的信息是否改变角色知情。

### 纸灯样例的三种入口

共同原著依据见 [sample-novel.md](../assets/sample-novel.md)，以下是入口比较，不是三套新增情节。

1. 背景入口：介绍乔禾做过十二版灯、准备参展、害怕失败。事实成立，但观众暂时不知道当下会失去什么，适合后移进反应与查证。
2. 编号异常入口：先看到裂灯的“样十二”与清单“展十七”。适合偏解谜版本，但需要很快明确指控与除名，否则像孤立谜题。
3. 拒签压力入口：除名确认书与笔被推来，许策说“签字。明天换人交展。”随后乔禾要求看灯。利害与行动紧连，最适合本例的署名主线，因此正文采用此版本。

入镜显示的是待签文件，除名尚未生效；对白短句可以作为早期抓手，整个首节拍还包含理解背景、反应与动作，不将首节拍全部标成3秒。

## 4. 节奏分三层检查

**全剧层**：主角目标、对手能力与问题条件是否逐步变化；关键揭示是否改变策略；结局是否兑现开头承诺。大转折不能只是重复同级冲突。短篇可合并节点，长篇可形成多段任务，不照抄固定比例。

**单集层**：明确入口、主要任务、阶段变化、反馈和下集问题。可用 `事件/期待 → 行动受阻 → 新支点/选择 → 局面改变 → 反馈/下一步` 排材料，但不强制每集有身份反转或完整击败对手。悬疑的阶段进展可以是排除一个解释、取得关键线索或改变调查方向。

**场与节拍层**：人物行动引来反行动，令信息、关系、风险、选择或结果发生变化。安静的停顿可以让人物接受后果，重复画面也可改变意义；无变化且无理解作用的段落删并。

## 5. 逐拍找变化与升级

修节奏时，用一句话检查每个关键节拍：`入拍状态 → 谁做了什么/谁反制 → 出拍状态`。需要时在创作资料用以下简表，不能把表格混进正文解析输入。

| 节拍 | 入拍任务/判断 | 行动与阻碍 | 信息/关系/选择/风险/结果的变化 | 下一拍为什么发生 |
|---|---|---|---|---|

如果删掉一拍不会影响理解、人物选择、铺垫、反应或后续因果，优先合并或删除。若它是唯一证据来源或情绪过渡，即使没有大冲突也要保留并压缩。

升级至少改变一项条件：时间更紧、损失明确、行动受限、证据可信度改变、盟友立场改变、代价变大或主角策略切换。音量更大、换人继续嘲笑、同一句狠话换说法都不构成有效升级。

例如纸灯样例：要求退出 → 编号异常 → 对手否认编号意义 → 核对成灯 → 撤回除名 → 更早申请曝光。每拍改变查证或追问的条件；没有把三轮辱骂当作三次升级。

## 6. 反转在节奏中怎样落地

把重大反转展开为五个功能，不限定每个功能各占一拍：

1. **建立预期**：谁认为事情会怎样，为什么这个判断可信。
2. **埋可回看线索**：线索先出现，有当时合理的表面用途，不必让人物立刻理解。
3. **执行揭示**：新证据被核对，或已建立的能力/资源被使用，改变判断或局面。
4. **让反馈落地**：当事人改口、停止程序、反制、失去资源、承担代价或改变选择。
5. **转向后续任务**：在保留当前兑现的前提下，出现更深问题或结果代价。

安排节拍时给线索、揭示和反馈留真实容量。重大后果可跨集，但已许诺的即时反馈不要每次拖到下一集。双重反转的第二层必须有自己的支点；它可以重释第一层原因，不能无依据抹掉第一层事实。

纸灯例：第一层是成灯没有坏，反馈为除名撤回；事前申请先形成集尾疑问，第二集的接任人和陆岚承认才揭示利益安排。再以留下记录和退回申请兑现结果。第一集异常出现时不提前宣称两层已经揭晓。

## 7. 用时长预算决定删留

先配置用户目标，再按 `max(配音时间+停顿, 同步动作) + 独立动作` 估算各拍。独立行动、物件阅读、惊讶后的判断和选择都需要时间；不让字幕、快切、多人台词挤在一秒里假装信息已被理解。

超时先删重复说明、同级施压、已知背景和多余场景，再压缩转场；不先删掉反转支点或反馈。低于预算时检查是否遗漏必要行动或理解过程，不能靠无意义停顿和反复展示物件凑秒。台词单位默认4/秒只是项目估算，实际语气和语言要演读校正。

用户要强节奏时，优先前置有效行动、缩短等待、让对手及时反制、揭示后迅速给到可见结果。用户要慢热时，保留情绪与关系积累，但每段仍承担叙事任务。

## 8. 交稿前的三次回看

- **只看开头**：能否指出抓手、当前人物目标、损失与第一项行动？看不懂时补最少信息；没有主线时换入口。
- **只看正文变化**：能否连成行动—阻碍—新选择的链？长期原地挨骂时重组行动；全程胜利时补可信代价和反行动。
- **从反转往前回看**：线索和权限是否真实出现，知情是否有来源，揭示是否足够，反馈是否落地，下集是否承接？缺项时修因果，不用加“反转”标签弥补。

这些判断属于内容审读。格式脚本和时长报告不能证明开头抓人、节奏有效或观众留存；在交付中区分已检查的具体文本与尚未验证的成片效果。

## 9. 开头与整集、长线联动

把抓手接到主角第一行动，核对本集阶段反馈和后续承诺推进，见 [adaptation-decisions.md](adaptation-decisions.md) 第4节。静音看开场辅助发现视觉抓手缺失，但对白驱动入口不因此判失败。0–3、3–8、8–15秒只作容量参考。节奏诊断与修法见该文第6节。
